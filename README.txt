NANDHINI AI — OFFLINE TAMIL COMPANION

This is an offline-first mobile-friendly web demo. It uses local built-in reply rules and makes no API calls. No server, account, API key, or payment is required to use the typed chat once the files are on the phone.

HOW TO USE ON ANDROID
1. Extract this ZIP using your phone's file manager or an archive app.
2. Open index.html in a browser if your phone offers that option.
3. Type a message and tap Send. Built-in replies work without internet.
4. Voice output uses text-to-speech voices already installed on Android. Download/install the Tamil voice in Android Text-to-speech settings beforehand if available.

IMPORTANT LIMITS
- This is NOT an APK; this ZIP cannot be installed as a normal Android app directly.
- Browser microphone speech recognition often needs an online service and may not work offline. Offline typing is the reliable mode; speech input works only if your device/browser supports offline recognition and the relevant language pack is installed.
- This is not a full generative AI model. It replies using local rules, so it cannot answer every question.
- For PWA installation and service-worker caching, the files must be opened from an HTTPS host once. After the first successful load, the cached interface can reopen offline.
- No chat text is sent to any server by this demo.
